🎓 HOW IT WORKS (SIMPLIFIED):

Every new candle:
  1. Scan for patterns (Double Tops, H&S, Triangles, etc.)
  2. Validate pattern geometry (no wick crossing)
  3. Calculate success probability
  4. If probability ≥ 75%, execute trade
  5. Manage with automatic stop/target/breakeven

Pattern Quality Formula:
  How well price matches ideal pattern shape (0-100%)

Probability Formula:
  (Quality × 40%) + (Momentum × 20%) + (Vol × 20%) +
  (R:R × 20%) + Bonus (5-8%)

Position Size Formula:
  Risk$ = min(Equity × 4%, Equity × 0.25%)
  Kelly Fraction = p - (1-p)/RR
  Lots = Risk$ / (Stop Distance × Point Value) × Kelly
